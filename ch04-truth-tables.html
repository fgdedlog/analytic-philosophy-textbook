Learning objectives

  • state the truth tables for the five connectives and explain truth-functionality;
  • compute the truth value of any formula under a valuation, and construct full truth tables;
  • classify formulas as tautologies, contradictions or contingent;
  • test pairs of formulas for equivalence, sets for consistency, and arguments for validity;
  • use the short (reductio) truth-table method;
  • know the key equivalences — De Morgan, contraposition, distribution, exportation and others;
  • explain and assess the “paradoxes” of the material conditional.

Truth-functional connectives

Classical logic assumes that every sentence is either true (T) or false (F), and not both. The connectives of propositional logic are truth-functional: the truth value of a compound depends only on the truth values of its components. So each connective can be defined by a truth table that lists the value of the compound for every combination of values of its parts.

Negation

¬A is true when A is false, and false when A is true.

The conditional

A → B is false only when the antecedent is true and the consequent false; true otherwise.

Truth table for p → q — contingent
pqp → q
TTT

This is the material conditional. The first two rows are uncontroversial: “if A then B” is true when both are true, and certainly false when A is true and B false. The last two rows — a false antecedent makes the conditional true — are more surprising. We discuss them at the end of the chapter. For now, note that a truth-functional conditional has to give some value in these rows, and that “true” is the only choice that makes A → B differ from every other connective while keeping modus ponens valid and A → A always true.

Computing truth values

A valuation assigns T or F to each sentence letter. (In propositional logic, a valuation is what we mean by an interpretation.) To compute the value of a complex formula under a valuation, work from the inside out, following the construction of the formula: first the smallest subformulas, finally the main connective.

Worked example

Let p = T, q = F, r = T. Compute ¬(p ∧ q) → (q ∨ ¬r).

  1. p ∧ q = T ∧ F = F.
  2. ¬(p ∧ q) = ¬F = T.
  3. ¬r = ¬T = F.
  4. q ∨ ¬r = F ∨ F = F.
  5. Main connective: ¬(p ∧ q) → (q ∨ ¬r) = T → F = F.

Full truth tables

A full truth table lists every valuation of the formula's sentence letters. With n letters there are 2n rows: 2 for one letter, 4 for two, 8 for three, 16 for four. To be sure you get every row exactly once, use the standard pattern (used throughout this book and in the truth-table tool): in the first column alternate blocks of T and F each half the height of the table; in the next, blocks half that size; and so on, until the last column alternates T, F, T, F. The first row makes every letter true, the last every letter false.

Then add a column for each subformula in order of construction, finishing with the whole formula. Here is the table for the formula of the worked example:

Tautologies, contradictions and contingencies

Truth tables classify formulas into three kinds.

  • A tautology is true in every row. Example: p ∨ ¬p (the law of excluded middle).
  • A contradiction is false in every row. Example: p ∧ ¬p.
  • A contingent formula is true in some rows and false in others. Example: p → q.
Truth table for p ∨ ¬p — a tautology
p¬pp ∨ ¬p
TFT
FTT
Truth table for p ∧ ¬p — a contradiction
p¬pp ∧ ¬p

Tautologies are the logical truths of propositional logic: true whatever the facts are, purely in virtue of their form. Their negations are contradictions, and vice versa. Note that ¬(p ∧ ¬p), the law of non-contradiction, is also a tautology.

Here is a less obvious tautology, known as Peirce's law:

Quick check Classify (p → q) ∨ (q → p).

If q is true, p → q is true; if q is false, q → p is true. Either way the disjunction is true. This is one of the "paradoxes" discussed at the end of the chapter.

Equivalence, consistency and entailment

Logical equivalence

Two formulas are logically equivalent if they have the same truth value in every row of a joint truth table. Equivalent formulas say the same thing, as far as truth conditions go. For example, p → q and ¬p ∨ q are equivalent:

Truth table for (p → q) ↔ (¬p ∨ q) — a tautology
pqp → q¬p¬p ∨ q(p → q) ↔ (¬p ∨ q)

FTTTTT

As the table illustrates, A and B are equivalent exactly when A ↔ B is a tautology. You can check any pair with the equivalence checker.

Consistency

A set of formulas is consistent (or satisfiable) if there is at least one row in which all of them are true; otherwise it is inconsistent. {p → q, p, ¬q} is inconsistent: no row makes all three true.

Entailment and validity

A set of premises Γ entails a conclusion C, written Γ ⊨ C, if there is no row in which every premise is true and C is false. An argument is valid in propositional logic just when its premises entail its conclusion. This makes precise the informal definition of Chapter 2: the “possible situations” are the rows of the truth table.

The truth-table test for validity. Draw a joint truth table for the premises and conclusion. Look for a row in which all premises are true and the conclusion false — a counterexample row. If there is none, the argument is valid. If there is one, it is invalid, and the row shows how the premises can be true and the conclusion false.

Modus tollens is valid

Truth table for p → q, ¬q ∴ ¬p: valid

The only row in which both premises are true (the last, shaded green) makes the conclusion true too. Valid.

The third row (red) makes both premises true and the conclusion false: p = F, q = T. Invalid.

The concepts are connected. For any formulas:

  • A ⊨ B if and only if A → B is a tautology;
  • A1, …, An ⊨ C if and only if the set {A1, …, An, ¬C} is inconsistent;
  • C is a tautology if and only if it is entailed by the empty set of premises, written ⊨ C.

The second point explains a striking fact: an inconsistent set of premises entails every conclusion. If no row makes all the premises true, there is certainly no row making them true and the conclusion false. So p, ¬p ⊨ q. This is the principle of explosion, or ex falso quodlibet (“from a falsehood, anything”). Similarly, a tautology is entailed by any premises at all. Some logicians regard these results as unacceptable; see relevance and paraconsistent logic in Chapter 9.

There is no row in which all premises are true, so there is no counterexample row.

The short truth-table method

Full tables grow fast: 5 letters need 32 rows, 10 need 1,024. The short truth-table method (also called the reductio or “backwards” method) searches directly for a counterexample. Assume the conclusion is F and every premise is T, and work out what values this forces on the sentence letters.

  • If the assumption forces some letter to be both T and F — a contradiction — then no counterexample exists, and the argument is valid.
  • If you reach a consistent assignment, it is a counterexample, and the argument is invalid.

The method works best when values are forced: a false conditional forces T antecedent and F consequent; a true conjunction forces both conjuncts true; a false disjunction forces both disjuncts false. When a value is not forced (for example a true disjunction), you must consider each possibility in turn — and the argument is valid only if every possibility leads to contradiction.

Example 1 (valid)

Test p → q, q → r ⊨ p → r.

  1. Suppose the conclusion p → r is F. Then p = T and r = F.
  2. Premise 1, p → q, is T, and p = T, so q = T.
  3. Premise 2, q → r, is T, and q = T, so r = T.
  4. But r = F from step 1. Contradiction. So no counterexample is possible: valid.

Example 2 (invalid)

Test (p ∧ q) → r, ¬r ⊨ ¬p.

  1. Conclusion ¬p F, so p = T.
  2. Premise 2, ¬r, T, so r = F.
  3. Premise 1, (p ∧ q) → r, T with r = F, so p ∧ q must be F. Since p = T, q = F.
  4. Check: p = T, q = F, r = F makes both premises T and the conclusion F. No contradiction: invalid, and this is the counterexample.

Example 3 (cases needed)

Test the constructive dilemma p ∨ q, p → r, q → r ⊨ r.

  1. Conclusion F: r = F.
  2. From p → r T and r F: p = F. From q → r T and r F: q = F.
  3. Then p ∨ q = F, contradicting premise 1. Valid.

Here the forced values happened to settle everything. Had we started with the disjunction p ∨ q, we would have had to split into cases (p = T, or q = T), closing each separately.

Key equivalences

The following equivalences are used constantly — in simplifying formulas, in translation, and as derived rules in proofs. Each can be checked by truth table (try them in the equivalence checker). Here ⇔ means “is equivalent to”; it is not a symbol of the object language.

NameEquivalence
Double negation¬¬A ⇔ A
De Morgan's laws¬(A ∧ B) ⇔ ¬A ∨ ¬B
¬(A ∨ B) ⇔ ¬A ∧ ¬B
CommutationA ∧ B ⇔ B ∧ A; A ∨ B ⇔ B ∨ A
Association(A ∧ B) ∧ C ⇔ A ∧ (B ∧ C); likewise for ∨
DistributionA ∧ (B ∨ C) ⇔ (A ∧ B) ∨ (A ∧ C)
A ∨ (B ∧ C) ⇔ (A ∨ B) ∧ (A ∨ C)

Negated conditional¬(A → B) ⇔ A ∧ ¬B
ContrapositionA → B ⇔ ¬B → ¬A
Exportation(A ∧ B) → C ⇔ A → (B → C)
BiconditionalA ↔ B ⇔ (A → B) ∧ (B → A)
A ↔ B ⇔ (A ∧ B) ∨ (¬A ∧ ¬B)
Negated biconditional¬(A ↔ B) ⇔ A ↔ ¬B
IdempotenceA ∧ A ⇔ A; A ∨ A ⇔ A
AbsorptionA ∧ (A ∨ B) ⇔ A; A ∨ (A ∧ B) ⇔ A
Conditional with disjunctive antecedent(A ∨ B) → C ⇔ (A → C) ∧ (B → C)

And some non-equivalences that students often assume:

  • A conditional is not equivalent to its converse: p → q and q → p differ (that is why affirming the consequent fails).
  • A conditional is not equivalent to its inverse: p → q and ¬p → ¬q differ (denying the antecedent).
  • ¬(p ∧ q) is not equivalent to ¬p ∧ ¬q.
  • (p → q) → r is not equivalent to p → (q → r): the conditional is not associative.
  • (p ∧ q) → r is not equivalent to (p → r) ∧ (q → r), though it is equivalent to (p → r) ∨ (q → r).

Quick check Which formula is equivalent to ¬(p → q)?

A conditional is false exactly when its antecedent is true and consequent false.

Functional completeness

Are five connectives enough? There are 16 possible two-place truth functions (each of the 4 rows can be T or F). A set of connectives is functionally complete if every truth function can be expressed using only those connectives. {¬, ∧, ∨} is functionally complete: for any truth table, take a disjunction of conjunctions, one conjunction for each row where the formula is true (this is called disjunctive normal form). Since A ∨ B ⇔ ¬(¬A ∧ ¬B), even {¬, ∧} suffices, as does {¬, →}. Remarkably, a single connective — “not both” (the Sheffer stroke, NAND) — is functionally complete on its own. In this sense our five connectives are a convenience: they are chosen because they correspond reasonably well to English words.

The paradoxes of material implication

The material conditional makes the following valid:

  1. q ⊨ p → q: a true consequent makes any conditional true. (“The moon is made of cheese only if 2 + 2 = 4” comes out true.)
  2. ¬p ⊨ p → q: a false antecedent makes any conditional true. (“If Paris is in Germany, then I am a giraffe” comes out true.)
  3. ⊨ (p → q) ∨ (q → p): of any two sentences, one materially implies the other.
  4. ¬(p → q) ⊨ p: denying a conditional commits you to its antecedent. (“It's not true that if God exists, prayers are answered” seems to entail that God exists!)

These are called “paradoxes”, but they are not contradictions — they are consequences of the definition that strike many people as wrong about English “if”. What should we say?

In defence of the material conditional

  • The argument from the falsity row. Everyone agrees “If A, B” is false when A is true and B false. If “if” is truth-functional at all, the other rows must be T: making the third row F turns → into ↔; making the fourth row F makes “if A, B” equivalent to plain B (so “if A, A” would no longer be a logical truth); making both F turns it into ∧. None of these is acceptable.
  • Promises and bets. I say: “If you pass, I'll buy you dinner.” You fail. Did I break my promise? No. Since I did not speak falsely, it is natural to say what I said was not false — and in classical logic, not false means true.
  • General claims. “For every number n, if n is greater than 2 and prime, n is odd” should be true. But it is true only if each instance, including “if 4 is greater than 2 and prime, 4 is odd” (false antecedent), is true.
  • Grice's defence. Paul Grice argued that the oddity of the paradoxes is pragmatic, not semantic. It is misleading to assert “If p, q” when you know that q is true — you should just say “q”. Saying something weaker than you are in a position to say breaks a conversational maxim; the conditional is true, but asserting it is inappropriate. (See Chapter 10.)

Against

  • Some conditionals are plainly not truth-functional. Counterfactuals — “If Oswald had not shot Kennedy, someone else would have” — have false antecedents, but some are true and some false. The material conditional cannot tell them apart.
  • Many indicative conditionals seem to require a connection between antecedent and consequent. The probability we assign to “If A, B” seems to be the conditional probability of B given A, not the probability of ¬A ∨ B (a view associated with Ernest Adams and Dorothy Edgington).

The standard position among logicians is that the material conditional is the best truth-functional approximation to “if”, and that it is exactly right for mathematics and for many purposes in philosophy, but that some English conditionals require richer treatments: strict conditionals, and the Lewis–Stalnaker theory of counterfactuals (Chapter 9). When we translate into propositional logic, we accept the material conditional as an idealisation.

Summary

  • Each connective is defined by a truth table: ¬ flips; ∧ needs both; ∨ needs at least one; → is false only for T → F; ↔ needs the same value.
  • A full truth table for n letters has 2n rows. Tautologies are true in all rows; contradictions in none; contingent formulas in some.
  • Equivalent formulas agree in every row. A set is consistent if some row makes all its members true. Γ ⊨ C if no row makes all of Γ true and C false.
  • An argument is valid iff its premises together with the negation of its conclusion are inconsistent; inconsistent premises entail anything.
  • The short truth-table method assumes a counterexample and either finds one (invalid) or derives a contradiction (valid).
  • Key equivalences include double negation, De Morgan, distribution, contraposition, exportation and the material conditional.
  • The material conditional yields “paradoxes”; they can be defended (e.g. by Grice) but motivate alternative accounts of conditionals.

Key terms

Truth-functional
A connective is truth-functional when the truth value of the compound depends only on the truth values of its parts.
Truth table
A table listing the truth value of a formula under every assignment of truth values to its sentence letters.
Interpretation
An assignment of meanings to the non-logical symbols of a formal language; in propositional logic, a row of a truth table.
Material conditional
The truth-functional conditional: A → B is false only when A is true and B false.
Tautology
A formula true in every row of its truth table.
Contradiction
A formula false in every row of its truth table; more generally, a statement that cannot be true.
Contingent
(Of a formula) true in some rows of its truth table and false in others; more generally, neither necessary nor impossible.
Logical equivalence
Two formulas are equivalent when they have the same truth value in every interpretation.
Entailment
Γ entails A (Γ ⊨ A) when there is no interpretation making every member of Γ true and A false.
Valid
(Of an argument) such that it is impossible for the premises to be true and the conclusion false.
Explosion
The principle that from a contradiction anything follows (ex falso quodlibet).
De Morgan's laws
The equivalences ¬(A ∧ B) ⇔ ¬A ∨ ¬B and ¬(A ∨ B) ⇔ ¬A ∧ ¬B.
Contraposition
The equivalence of A → B with ¬B → ¬A.
Law of excluded middle
The principle that every sentence of the form A ∨ ¬A is true.
Law of non-contradiction
The principle that no sentence of the form A ∧ ¬A is true.

Exercises

Exercise 4.1

Let p = T, q = F, r = F. Compute: (a) p ∧ (q ∨ ¬r) (b) (p → q) → r (c) ¬(p ↔ q) ∧ ¬r (d) (q → r) ↔ ¬p

Show solution

(a) ¬r = T, so q ∨ ¬r = T, so the whole is T. (b) p → q = F, so F → F = T. (c) p ↔ q = F, so its negation is T; ¬r = T; whole = T. (d) q → r = T; ¬p = F; T ↔ F = F.

Exercise 4.3

Use truth tables to decide which pairs are equivalent: (a) p → (q ∨ r) and (p → q) ∨ (p → r); (b) (p ∨ q) → r and (p → r) ∨ (q → r); (c) ¬(p ↔ q) and ¬p ↔ q.

Show solution

(a) Equivalent. (b) Not equivalent: with p = T, q = F, r = F, the first is F but the second is T (since q → r is T). The correct equivalent of (p ∨ q) → r is the conjunction (p → r) ∧ (q → r). (c) Equivalent.

Exercise 4.5

Use the short truth-table method to test: (a) p → (q ∧ r), ¬r ∴ ¬p (b) p → q, r → q ∴ p → r (c) (p ∨ q) → r, ¬r ∴ ¬p ∧ ¬q

Show solution

(a) Conclusion F: p = T. Premise 2 T: r = F. Premise 1 T with p = T: q ∧ r = T, so r = T. Contradiction: valid.

(b) Conclusion F: p = T, r = F. Premise 1 T: q = T. Premise 2: r → q = F → T = T. Consistent: invalid, counterexample p = T, q = T, r = F.

(c) Conclusion F: ¬p ∧ ¬q F, so at least one of p, q is T — not forced, so look at the premises first. Premise 2: r = F. Premise 1 T with r = F: p ∨ q = F, so p = F and q = F. Then ¬p ∧ ¬q = T, contradicting our assumption. Valid.

Exercise 4.6

Is the set {p ∨ q, ¬p ∨ ¬q, p → q} consistent? If so, give a row that makes all members true.

Show solution

Consistent: p = F, q = T makes all three true (p ∨ q = T, ¬p ∨ ¬q = T, p → q = T).

Exercise 4.7

Explain, using truth tables, why A ⊨ B holds exactly when A → B is a tautology.

Show solution

A → B is false in a row exactly when A is true and B false in that row. So A → B is a tautology (false in no row) exactly when there is no row with A true and B false — which is the definition of A ⊨ B.

Exercise 4.8

“If I am in Edinburgh, I am in Scotland. So either if I am in Edinburgh I am in France, or if I am in France I am in Scotland.” Show that this is valid in propositional logic. Does this show the material conditional is a poor model of “if”? Discuss briefly.

Show solution

Formalise as e → s ∴ (e → f) ∨ (f → s). In fact the conclusion is a tautology by itself, so the argument is valid whatever the premise says. Short method: if the conclusion were F, both disjuncts would be F; e → f F requires f = F, but f → s F requires f = T — contradiction. The conclusion sounds absurd in English, suggesting that English “if” is not always material. A Gricean might reply that the disjunction is true but unassertable: nobody would assert a disjunction of conditionals when they are in a position to assert something stronger (here, that I am not in France, which makes f → s true).
