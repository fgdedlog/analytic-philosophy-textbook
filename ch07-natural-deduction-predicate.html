Learning objectives

  • state and apply the four quantifier rules ∀E, ∀I, ∃I and ∃E, including the restrictions on names in ∀I and ∃E;
  • explain why those restrictions are needed, using counterexamples;
  • use the identity rules =I and =E;
  • prove the quantifier negation equivalences and use them as a derived rule;
  • recognise common mistakes in quantifier proofs;
  • use truth trees for simple predicate-logic arguments.

Extending the system

All the rules of Chapter 5 remain in force; predicate-logic sentences are combined by the same connectives. We add an introduction and an elimination rule for each quantifier, and two rules for identity. Throughout, we write A(x) for a formula in which the variable x may occur free, and A(c) for the result of replacing every free occurrence of x by the name c. For example, if A(x) is Fx → Rxb, then A(a) is Fa → Rab.

Every line of a proof must be a sentence — no free variables. Variables appear only inside quantified formulas; when we “take an instance” we always substitute a name.

Universal elimination (∀E)

If everything is F, then any particular thing is F. ∀E: from ∀xA(x) infer A(c), for any name c. (Older books call this universal instantiation, UI.)

Worked proof: Socrates is mortal

The instance must replace every free occurrence of the variable by the same name. From ∀xRxx you may infer Raa, but not Rab.

Existential introduction (∃I)

If a particular thing is F, then something is F. ∃I: from A(c) infer ∃xA(x). Here you may replace some or all occurrences of c by x. From Raa you may infer ∃xRxx, ∃xRxa or ∃xRax: each is true if Raa is.

This is valid because, by convention, every domain is non-empty. (In a “free logic” that allows empty domains, it would fail.)

Universal introduction (∀I)

How can we prove that everything is F? A geometry teacher proves that every triangle has angles summing to 180° by saying “let ABC be any triangle” and reasoning about it without assuming anything special about ABC. If the reasoning works for an arbitrary triangle, it works for all. ∀I captures this.

∀I: from A(c) infer ∀xA(x), provided that:

  1. the name c does not occur in any undischarged assumption or premise; and
  2. c does not occur in ∀xA(x) — that is, every occurrence of c is replaced by x.

Older books call this universal generalisation (UG). A name meeting these conditions is called an arbitrary name.

Why the restrictions?

Without restriction 1, we could argue: “Socrates is wise; therefore everything is wise.”

The name s occurs in a premise, so we have assumed something special about it; it is not arbitrary. Without restriction 2, from ∀xRxx (“everyone is as tall as themselves”) we could get Raa by ∀E and then ∀xRxa (“everyone is as tall as a”), which does not follow.

Existential elimination (∃E)

Suppose we know that something is F, but not what. How can we use this? In ordinary reasoning we say: “Something is F — call it c. Then …” and reason to a conclusion that does not mention c. Since c was just a label for whatever is F, the conclusion holds outright.

∃E: from ∃xA(x) and a subproof that assumes A(c) and ends with B, infer B, provided that:

  1. c does not occur in any undischarged assumption or premise outside the subproof;
  2. c does not occur in ∃xA(x);
  3. c does not occur in B.

In practice: always use a brand-new name for the assumption of an ∃E subproof.

Identity rules

=I: at any point, write c = c for any name c, citing no lines. (Everything is identical to itself.)

=E: from a = b and a sentence A containing a, infer the result of replacing some or all occurrences of a by b (or of b by a). This is Leibniz's Law, the indiscernibility of identicals: if a and b are one and the same, whatever is true of one is true of the other.

Strategy for quantifier proofs

  1. Existential premises first. If you have ∃xA(x) available, open an ∃E subproof with a new name early, and aim for your goal inside it.
  2. Then instantiate universals with ∀E, using the names you need (often the name just introduced by ∃E).
  3. Universal goal: aim for an instance A(c) with a fresh name c, then ∀I.
  4. Existential goal: aim for an instance A(c) for some name, then ∃I.
  5. Negated quantifiers: convert with CQ, or argue indirectly.

A useful rule of thumb: introduce names with ∃E before you instantiate universals with ∀E, because ∃E needs a new name while ∀E can use any name.

Common mistakes

Using ∃E with a name that is not new

The second ∃E assumes Ga, using the name a already used for the thing that is F. That assumes the F and the G are the same thing — exactly what we have no right to assume.

Letting the instance escape the subproof

Knowing that something is F does not tell us that a is F. The conclusion of ∃E must not contain the new name.

The quantifier-shift fallacy

Line 4 generalises on a, which occurs in the undischarged assumption on line 3. The b was chosen for a; we cannot conclude that it works for everything.

Instantiating with a variable

From ∀xFx you may not write Fx: it is not a sentence. Always instantiate with a name.

Truth trees for predicate logic

Trees extend to predicate logic with four new rules:

¬∀xA(x)write ∃x¬A(x). Tick.

The open branch contains Fa, Gb, ¬Ga, ¬Fb. Reading off a model with one object for each name:

Interpretation

In this interpretation
  • ∃xFx is true
  • ∃xGx is true
  • ∃x(Fx ∧ Gx) is false

Unlike propositional trees, predicate trees need not terminate: a formula like ∀x∃yRxy generates a new name, which generates a new instance of the universal, which generates another new name, and so on forever. This is not a defect of the method but a reflection of a deep fact: as Chapter 8 explains, there can be no procedure that always decides validity in predicate logic.

Summary

  • ∀E: from ∀xA(x) infer any instance A(c). ∃I: from A(c) infer ∃xA(x).
  • ∀I: from A(c) infer ∀xA(x), provided c is arbitrary: it occurs in no undischarged assumption or premise, and not in the conclusion.
  • ∃E: from ∃xA(x) and a subproof from A(c) to B, infer B, provided c is new — not in any outside assumption, not in ∃xA(x), not in B.
  • =I: c = c. =E: substitute identicals (Leibniz's Law).
  • CQ is a derived rule for moving negation across quantifiers.
  • Predicate trees add rules for the quantifiers; they may fail to terminate.

Key terms

Arbitrary name
In natural deduction, a name used in ∀I or ∃E about which nothing special has been assumed.
Universal instantiation
Another name for ∀E.
Universal generalisation
Another name for ∀I.
Leibniz's Law
The indiscernibility of identicals: if a = b then a and b have all the same properties.
Indiscernibility of identicals
Leibniz's Law: if a = b, then whatever is true of a is true of b.
Quantifier negation
The equivalences ¬∀xA ⇔ ∃x¬A and ¬∃xA ⇔ ∀x¬A.
Truth tree
A proof method (semantic tableau) that tests for consistency by systematically searching for a model.

Exercise 7.9

Explain in your own words why ∃E requires a new name. Illustrate with an argument that would be “provable” without the restriction.

Show solution

The assumption A(c) in an ∃E subproof says only that some object, which we label c, satisfies A. If c already names a particular object about which we know something, the assumption smuggles in the claim that this very object satisfies A. Example: from “Someone is a spy” and “Fred is honest” we could assume “Fred is a spy” and conclude “Someone is an honest spy” — invalid. The faulty attempt above with ∃xFx, ∃xGx shows the same pattern.
