Truth-table generator

Type a formula of propositional logic to get its full truth table, with a column for every subformula and a verdict: tautology, contradiction or contingent. Type an argument (premises separated by commas, then therefore) to test it for validity.

  • Sentence letters: any single letter, optionally followed by digits (p, q, r1, A, B) — except lower-case v, which means “or”. Up to 10 different letters.
  • Precedence (tightest first): ¬, then ∧, then ∨, then →, then ↔. So ~p & q -> r is read as (¬p ∧ q) → r.
  • ∧ and ∨ group to the left; → and ↔ group to the right: p -> q -> r means p → (q → r). When in doubt, use brackets — the “Read as” line shows how your input was understood.
  • Rows are listed in the standard order used in this book: the first row makes every letter true, the last makes every letter false.
  • This tool is for propositional logic only. Quantifiers and predicates cannot be checked by truth tables (see Chapter 8 for why).
