Lower-case v always means “or”, so it cannot be used as a sentence letter. Any kind of bracket — ( ), [ ] or { } — may be used. The truth-table and equivalence tools handle propositional formulas only; the proof checker accepts the full predicate language.

Metalogical symbols (not part of the object language): ⊨ semantic entailment (“no row/model makes the premises true and the conclusion false”); ⊢ provability (“there is a proof”); ∴ “therefore”.

Grouping and precedence

From tightest to loosest: ¬, quantifiers → ∧ → ∨ → → → ↔. So ¬p ∧ q → r means ((¬p) ∧ q) → r. When in doubt, add brackets. ∧ and ∨ group to the left; → and ↔ group to the right (p → q → r is p → (q → r)).

Names a–s; variables t, u, w, x, y, z; predicates capital letters, arguments written directly after them: Fa, Rxy.

Truth tables at a glance

A formula is a tautology if true on every row, a contradiction if false on every row, and contingent otherwise. An argument is valid iff no row makes every premise true and the conclusion false.

Natural deduction: basic rules

In each rule, m, n are line numbers and i–j is a closed subproof whose first line (the assumption) is i and last line is j. Only lines that are accessible — not inside a subproof that has already closed — may be cited.

ConnectiveIntroductionElimination
∧∧I m, n: from A and B, infer A ∧ B∧E m: from A ∧ B, infer A (or B)
∨∨I m: from A, infer A ∨ B (or B ∨ A)∨E m, i–j, k–l: from A ∨ B, a subproof A … C and a subproof B … C, infer C
→→I i–j: from a subproof A … B, infer A → B→E m, n: from A → B and A, infer B
↔↔I i–j, k–l: from subproofs A … B and B … A, infer A ↔ B↔E m, n: from A ↔ B and A, infer B (or from B, infer A)
¬¬I i–j: from a subproof A … ⊥, infer ¬A¬E m, n: from A and ¬A, infer ⊥
⊥(by ¬E)X m: from ⊥, infer any A
indirect proofIP i–j: from a subproof ¬A … ⊥, infer A
premise / assumptionPR: a premise (top of the proof). AS: an assumption opening a new subproof.
reiterationR m: copy any accessible line

Aliases accepted by the checker: MP = →E, CP = →I, EFQ = X, ⊥I = ¬E, RAA (for ¬I or IP).

Important equivalences

Each of these has been checked by truth table when the site was built.

NameEquivalence
De Morgan¬(A ∧ B) ⟺ ¬A ∨ ¬B    ¬(A ∨ B) ⟺ ¬A ∧ ¬B
Material conditionalA → B ⟺ ¬A ∨ B
ContrapositionA → B ⟺ ¬B → ¬A
BiconditionalA ↔ B ⟺ (A → B) ∧ (B → A)
Negated conditional¬(A → B) ⟺ A ∧ ¬B
DistributionA ∧ (B ∨ C) ⟺ (A ∧ B) ∨ (A ∧ C)    A ∨ (B ∧ C) ⟺ (A ∨ B) ∧ (A ∨ C)
Exportation(A ∧ B) → C ⟺ A → (B → C)
Double negation¬¬A ⟺ A
Quantifier negation¬∀xA ⟺ ∃x¬A    ¬∃xA ⟺ ∀x¬A
Quantifier distribution∀x(A ∧ B) ⟺ ∀xA ∧ ∀xB    ∃x(A ∨ B) ⟺ ∃xA ∨ ∃xB

Not equivalent (common mistakes): A → B vs B → A (converse); ∀x(A ∨ B) vs ∀xA ∨ ∀xB; ∃x(A ∧ B) vs ∃xA ∧ ∃xB; ∀x∃y vs ∃y∀x.
