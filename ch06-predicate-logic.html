Learning objectives

  • explain why propositional logic is not enough and what predicate logic adds;
  • use names, predicates, variables and the quantifiers ∀ and ∃, and identify free and bound variables and the scope of quantifiers;
  • translate English sentences involving “all”, “some”, “no”, “only” and nested quantifiers;
  • define an interpretation (model) and determine the truth value of a sentence in a given model;
  • show that an argument is invalid by constructing a counter-model;
  • use identity to express numerical claims, and state Russell's theory of definite descriptions.

Beyond sentences

Recall the argument that defeated propositional logic in Chapter 3:

  1. P1All philosophers are mortal.
  2. P2Hypatia is a philosopher.
  3. CHypatia is mortal.

Its validity depends on structure inside the sentences: the same predicates (“is a philosopher”, “is mortal”) and the same name (“Hypatia”) recur, and the word “all” links them. Predicate logic (also called first-order logic, quantificational logic or the predicate calculus) represents this structure. It is the logic Frege invented, and it is powerful enough to formalise virtually all of mathematics.

The language

Names and predicates

  • Names (individual constants): lower-case letters a, b, c, …, s. Each picks out exactly one object. Example key: h: Hypatia; s: Socrates.
  • Predicates: capital letters A, B, …, Z. Each has an arity: the number of objects it applies to. One-place predicates express properties (Px: x is a philosopher); two-place predicates express relations (Lxy: x loves y); three-place predicates relate three things (Bxyz: x is between y and z).

An atomic sentence is a predicate followed by the right number of names: Ph (Hypatia is a philosopher), Lhs (Hypatia loves Socrates). Order matters: Lhs and Lsh say different things. Atomic sentences combine with the connectives exactly as in propositional logic: Ph ∧ ¬Mh, Lhs → Lsh.

Variables and quantifiers

To say something general we use variables x, y, z (also w, u, t) and two quantifiers:

  • the universal quantifier ∀x, read “for every x” or “for all x”;
  • the existential quantifier ∃x, read “there is at least one x such that” or “for some x”.

So ∀xMx says everything is mortal, and ∃xPx says something is a philosopher. Quantifiers range over a domain of objects fixed in advance — when discussing people, the domain might be all people, so that ∀xMx says every person is mortal.

Formation rules

  1. If F is an n-place predicate and t1, …, tn are names or variables, Ft1…tn is a formula. If t1 and t2 are names or variables, t1 = t2 is a formula.
  2. If A and B are formulas, so are ¬A, (A ∧ B), (A ∨ B), (A → B), (A ↔ B).
  3. If A is a formula and x a variable, ∀xA and ∃xA are formulas.
  4. Nothing else is a formula.

Scope, free and bound variables

The scope of a quantifier is the formula immediately following it. Like ¬, a quantifier applies to the smallest formula after it: in ∀xFx → Gx the quantifier's scope is just Fx, whereas in ∀x(Fx → Gx) it is the whole conditional.

An occurrence of a variable is bound if it lies within the scope of a quantifier using that variable; otherwise it is free. In ∀xFx → Gx, the x in Fx is bound but the x in Gx is free. A formula with no free variables is a sentence; only sentences are true or false. Gx on its own (“x is green”) is not true or false until we say what x is.

In the second formula, x is bound by ∀x and y by ∃y. In the others, some occurrence of x is outside the scope of any quantifier on x.

Translating with one quantifier

The four classic forms of Aristotelian logic translate as follows (domain: everything; Fx: x is a philosopher, Gx: x is wise).

EnglishTranslationEquivalent
All philosophers are wise.∀x(Fx → Gx)¬∃x(Fx ∧ ¬Gx)
Some philosophers are wise.∃x(Fx ∧ Gx)¬∀x(Fx → ¬Gx)
No philosophers are wise.∀x(Fx → ¬Gx)¬∃x(Fx ∧ Gx)
Some philosophers are not wise.∃x(Fx ∧ ¬Gx)¬∀x(Fx → Gx)

The golden rule: ∀ goes with →; ∃ goes with ∧.

  • ∀x(Fx ∧ Gx) says that everything is a wise philosopher — far too strong.
  • ∃x(Fx → Gx) says that there is something which, if it is a philosopher, is wise. That is true if there is anything at all that is not a philosopher (a false antecedent makes the conditional true) — far too weak.

Note that “All philosophers are wise”, translated as ∀x(Fx → Gx), is true if there are no philosophers at all (it is then “vacuously” true). Aristotle assumed that “All Fs are G” implies “Some Fs are G”; modern logic does not. If you want to express that there are philosophers and all of them are wise, write ∃xFx ∧ ∀x(Fx → Gx).

More English quantifier words

EnglishTranslation
Every / each / any philosopher is wise.∀x(Fx → Gx)
A philosopher is wise (generic).∀x(Fx → Gx)
A philosopher came to dinner.∃x(Fx ∧ Cx)
Only philosophers are wise.∀x(Gx → Fx)
Not all philosophers are wise.¬∀x(Fx → Gx)
Something is wise.∃xGx
Nothing is wise.¬∃xGx or ∀x¬Gx
Wise philosophers are rare (not translatable).—

“Only” reverses the direction of the conditional, just as “only if” does: “Only philosophers are wise” means anything wise is a philosopher. The indefinite article is ambiguous: “A whale is a mammal” is general, but “A whale swam past the boat” is existential. And “any” changes its force in context: “If anyone is wise, Hypatia is” means ∃xGx → Gh, while “If anyone is wise, they are happy” means ∀x(Gx → Hx).

Complex predicates

Adjectives and relative clauses become conjunctions inside the quantified formula. With Sx: x is a student, Lx: x studies logic, Px: x passes:

  • Every student who studies logic passes: ∀x((Sx ∧ Lx) → Px).
  • Some student who studies logic does not pass: ∃x(Sx ∧ Lx ∧ ¬Px).
  • No student passes unless they study logic: ∀x(Sx → (Px → Lx)), equivalently ∀x((Sx ∧ Px) → Lx).

Quick check Which translates “Only students who study logic pass” (domain: students)?

"Only" introduces the necessary condition: anyone who passes studies logic.

Quantifier negation

“Not everything is F” means “something is not F”; “nothing is F” means “everything is not F”. In symbols, the quantifier negation equivalences:

¬∀xA ⇔ ∃x¬A    ¬∃xA ⇔ ∀x¬A

These let you push a negation through a quantifier, flipping it. Combined with the propositional equivalences of Chapter 4, they show why the translations in the table above are equivalent: ¬∃x(Fx ∧ ¬Gx) ⇔ ∀x¬(Fx ∧ ¬Gx) ⇔ ∀x(¬Fx ∨ Gx) ⇔ ∀x(Fx → Gx).

Several quantifiers

The real power of predicate logic appears with relations and several quantifiers — exactly what Aristotelian logic could not handle. With domain: people, and Lxy: x loves y:

EnglishTranslation
Everyone loves everyone.∀x∀yLxy
Someone loves someone.∃x∃yLxy
Everyone loves someone (or other).∀x∃yLxy
There is someone whom everyone loves.∃y∀xLxy
Everyone is loved by someone.∀y∃xLxy
Someone loves everyone.∃x∀yLxy
Everyone loves themselves.∀xLxx
Someone loves nobody.∃x∀y¬Lxy (equivalently ∃x¬∃yLxy)

Order matters when the quantifiers are of different kinds. ∀x∃yLxy says that for each person there is someone they love — possibly a different person for each. ∃y∀xLxy says there is one particular person loved by everybody. The second entails the first, but not conversely. (Confusing them is called the quantifier-shift fallacy. A famous alleged example: “Every event has a cause, so there is something that causes every event.”) When the quantifiers are of the same kind, order does not matter: ∀x∀yLxy ⇔ ∀y∀xLxy.

A method for nested translation: paraphrase the English into “loglish” step by step. “Every philosopher admires some logician”: for every x, if x is a philosopher, then there is a y such that y is a logician and x admires y: ∀x(Px → ∃y(Ly ∧ Axy)).

More examples

Domain: people. Sx: x is a student; Tx: x is a teacher; Rxy: x respects y.

  • Every student respects some teacher: ∀x(Sx → ∃y(Ty ∧ Rxy)).
  • Some teacher is respected by every student: ∃y(Ty ∧ ∀x(Sx → Rxy)).
  • No student respects every teacher: ¬∃x(Sx ∧ ∀y(Ty → Rxy)).
  • Anyone who respects nobody is respected by nobody: ∀x(∀y¬Rxy → ∀z¬Rzx).

Quick check Which translates “Every student has read some book” on the reading where the book may differ from student to student? (Sx: x is a student; Bx: x is a book; Rxy: x has read y)

The universal comes first, so the book can depend on the student. The second option says one book has been read by every student. The third wrongly says that everything is a student.

Interpretations and truth

In propositional logic, an interpretation was a row of a truth table. In predicate logic it is richer. An interpretation (or model) consists of:

  1. a non-empty domain D of objects;
  2. for each name, an object in D that it refers to (its referent);
  3. for each one-place predicate, a set of objects in D (its extension: the things it is true of); for each two-place predicate, a set of ordered pairs; and so on.

Truth in an interpretation is then defined as follows. Fa is true iff the referent of a is in the extension of F; Rab is true iff the pair ⟨referent of a, referent of b⟩ is in the extension of R. Connectives work as before. ∀xA is true iff A is true whatever object in D we let x stand for; ∃xA is true iff A is true for at least one object in D.

Interpretations can use any objects at all — numbers are convenient. Here is one, with the truth values of several sentences in it (computed and checked by machine, as are all the models in this book):

Interpretation
  • Domain: {1, 2, 3}
  • a refers to 1
  • b refers to 2
  • Extension of F: {1, 2}
  • Extension of G: {2}
  • Extension of R: {⟨1,2⟩, ⟨2,3⟩, ⟨3,1⟩}
In this interpretation
  • Fa is true
  • Fb ∧ Gb is true
  • ∃x(Fx ∧ Gx) is true
  • ∀x∃yRxy is true
  • ∀x(Gx → Fx) is true
  • Ga is false
  • ∀x(Fx → Gx) is false
  • ∃y∀xRxy is false
  • ∃xRxx is false

Check some by hand. ∀x(Fx → Gx) is false because 1 is in the extension of F but not G. ∀x∃yRxy is true: 1 bears R to 2, 2 to 3, and 3 to 1. ∃y∀xRxy is false: no single object has everything bearing R to it.

Validity and counter-models

The semantic notions of Chapter 4 carry over with “interpretation” in place of “row”:

  • A sentence is logically true if it is true in every interpretation.
  • An argument is valid (Γ ⊨ C) if every interpretation that makes all the premises true makes the conclusion true.
  • Two sentences are equivalent if they are true in exactly the same interpretations.

There is a crucial difference: there are infinitely many interpretations (domains can be any size, including infinite), so we cannot check them all. To show an argument valid, we need a proof (Chapter 7). To show it invalid, we need only one interpretation in which the premises are true and the conclusion false — a counter-model.

Counter-model 1: affirming the consequent, quantified

“All philosophers are mortal. Socrates is mortal. So Socrates is a philosopher.” Formalised: ∀x(Fx → Gx), Gs ∴ Fs. A counter-model:

Interpretation
  • Domain: {1}
  • s refers to 1
  • Extension of F: {}
  • Extension of G: {1}
In this interpretation
  • ∀x(Fx → Gx) is true
  • Gs is true
  • Fs is false

Here the extension of F is empty, so the universal premise is vacuously true.

Counter-model 2: distributing ∃ over ∧

“Something is red and something is round, so something is red and round”: ∃xFx, ∃xGx ∴ ∃x(Fx ∧ Gx).

Interpretation
  • Domain: {1, 2}
  • Extension of F: {1}
  • Extension of G: {2}
In this interpretation
  • ∃xFx is true
  • ∃xGx is true
  • ∃x(Fx ∧ Gx) is false

Counter-model 3: the quantifier-shift fallacy

∀x∃yRxy ∴ ∃y∀xRxy. Take a two-element domain in which each object bears R only to itself:

Interpretation
  • Domain: {1, 2}
  • Extension of R: {⟨1,1⟩, ⟨2,2⟩}
In this interpretation
  • ∀x∃yRxy is true
  • ∃y∀xRxy is false

Each object bears R to something (itself), but nothing has everything bearing R to it. A natural-language version: “Everyone has a mother, so someone is everyone's mother.”

Counter-model 4: ∀ does not distribute over ∨

∀x(Fx ∨ Gx) ∴ ∀xFx ∨ ∀xGx. (Every number is even or odd; it does not follow that every number is even or every number is odd.)

Interpretation
  • Domain: {1, 2}
  • Extension of F: {1}
  • Extension of G: {2}
In this interpretation
  • ∀x(Fx ∨ Gx) is true
  • ∀xFx ∨ ∀xGx is false

Strategy for finding counter-models: start small (one or two objects), make the conclusion false first, then adjust the extensions so the premises are true. If the argument is in fact valid, you will keep failing — a sign to look for a proof instead.

Why not truth tables? A quantified sentence can be thought of as a big conjunction (∀) or disjunction (∃) over the domain. But the domain may be infinite, and some sentences are true in every finite domain yet false in an infinite one (or vice versa). There is no finite table to draw. In fact, as Chapter 8 explains, no mechanical procedure can decide validity for all of predicate logic.

Identity

The two-place predicate identity, written a = b, means that a and b are one and the same object (numerical identity, not mere similarity). We write a ≠ b for ¬a = b. Unlike other predicates, its interpretation is fixed: in every model, a = b is true iff a and b refer to the same object. With identity we can say much more.

“Other than”, “except”, “only”

  • Hypatia loves someone other than herself: ∃x(Lhx ∧ x ≠ h).
  • Everyone except Hypatia is a logician: ∀x(x ≠ h → Gx) ∧ ¬Gh (if “except” is taken to imply that Hypatia is not).
  • Only Hypatia is wise: Wh ∧ ∀x(Wx → x = h).
  • Hypatia is the wisest philosopher: Ph ∧ ∀x((Px ∧ x ≠ h) → Whx) (with Wxy: x is wiser than y).

  • ∀x∀y((Fx ∧ Fy) → x = y) is false

A note on “at least two”: without x ≠ y, the formula ∃x∃y(Fx ∧ Fy) would be true with just one F, since the variables x and y may take the same value.

Definite descriptions

How should we translate “The author of Waverley is Scottish”? A definite description — a phrase “the F” — looks like a name. But treating it as a name causes trouble when nothing fits the description. “The present King of France is bald” is surely not true; but is it false? If so, its negation, “The present King of France is not bald”, should be true — which seems wrong too, since there is no King of France.

Russell's solution, in “On Denoting” (1905), is that definite descriptions are not names at all but disguised quantifier phrases. “The F is G” says three things:

  1. there is at least one F (existence);
  2. there is at most one F (uniqueness);
  3. every F is G — or equivalently, that F is G.

Russell's analysis. “The F is G” ⇔ ∃x(Fx ∧ ∀y(Fy → y = x) ∧ Gx).

With Kx: x is presently King of France, Bx: x is bald, “The present King of France is bald” is ∃x(Kx ∧ ∀y(Ky → y = x) ∧ Bx). Since nothing is presently King of France, this is simply false.

What about “The present King of France is not bald”? Russell points out that it is ambiguous, because the negation can take different scope:

  • Narrow scope (the description has primary occurrence): there is exactly one King of France and he is not bald: ∃x(Kx ∧ ∀y(Ky → y = x) ∧ ¬Bx). False.
  • Wide scope (secondary occurrence): it is not the case that there is exactly one King of France who is bald: ¬∃x(Kx ∧ ∀y(Ky → y = x) ∧ Bx). True.
Interpretation
  • Domain: {1, 2}
  • Extension of K: {}
  • Extension of B: {1}
In this interpretation
  • ∃x(Kx ∧ ∀y(Ky → y = x) ∧ Bx) is false
  • ∃x(Kx ∧ ∀y(Ky → y = x) ∧ ¬Bx) is false
  • ¬∃x(Kx ∧ ∀y(Ky → y = x) ∧ Bx) is true

So the law of excluded middle is preserved — of “the King is bald” and its wide-scope negation, exactly one is true — without committing us to a bald or non-bald non-existent king. The analysis also explains how “The author of Waverley is Scott” can be informative, and how we can meaningfully deny existence (“The round square does not exist”). P. F. Strawson objected in “On Referring” (1950) that someone who says “The King of France is bald” does not assert that there is a King of France but presupposes it; when the presupposition fails, the statement is neither true nor false. Kripke's work on names (Chapter 10) continues the story.

What first-order logic leaves out

Our quantifiers range over objects, not properties; logic that quantifies over properties (“Napoleon had every quality of a great general”) is second-order. We have also omitted function symbols (such as “the father of x”), which can be added. And some English quantifiers cannot be expressed in first-order logic at all: “most philosophers are wise” cannot be defined from ∀ and ∃. Even so, first-order logic is the standard framework of analytic philosophy and of the foundations of mathematics, for reasons Chapter 8 explains.

Summary

  • Predicate logic adds names, predicates, variables, and the quantifiers ∀ and ∃ to propositional logic.
  • A sentence has no free variables. A quantifier's scope is the formula immediately following it.
  • “All Fs are G” is ∀x(Fx → Gx); “some F is G” is ∃x(Fx ∧ Gx); “no F is G” is ∀x(Fx → ¬Gx); “only Fs are G” is ∀x(Gx → Fx).
  • The order of mixed quantifiers matters: ∃y∀xRxy entails ∀x∃yRxy but not conversely.
  • An interpretation has a domain, referents for names and extensions for predicates. Validity is truth-preservation in all interpretations; a counter-model shows invalidity.
  • Identity lets us express “other than”, “only”, and numerical claims. Russell analysed “the F is G” as ∃x(Fx ∧ ∀y(Fy → y = x) ∧ Gx).

Key terms

Predicate
An expression that says something about one or more objects, e.g. "… is wise", "… loves …".
Atomic sentence
A sentence with no connectives or quantifiers, e.g. a sentence letter p or a predication Fa.
Quantifier
An expression of quantity: ∀ ("every") or ∃ ("some").
Universal quantifier
The symbol ∀, "for every …".
Existential quantifier
The symbol ∃, "there is at least one … such that".
Domain
The non-empty set of objects an interpretation of predicate logic is about; the quantifiers range over it.
Bound variable
An occurrence of a variable that falls within the scope of a quantifier using that variable.
Free variable
An occurrence of a variable not bound by any quantifier.
Scope
The part of a formula governed by a connective or quantifier.
Quantifier negation
The equivalences ¬∀xA ⇔ ∃x¬A and ¬∃xA ⇔ ∀x¬A.
Interpretation
An assignment of meanings to the non-logical symbols of a formal language; in propositional logic, a row of a truth table.
Model
An interpretation that makes a given sentence or set of sentences true.
Extension
The set of things a predicate applies to (or the referent of a name, or the truth value of a sentence).
Referent
The object a name or other expression picks out.
Counter-model
An interpretation in which the premises of an argument are true and its conclusion false.
Identity
The relation each thing bears to itself and to nothing else, written a = b.
Definite description
A phrase of the form "the F", e.g. "the present King of France".

Exercise 6.1

Translate, using Hx: x is a human, Mx: x is mortal, Gx: x is a god, z: Zeus. (a) No god is mortal. (b) Only humans are mortal. (c) Some humans are not mortal. (d) If Zeus is a god, then not every god is mortal. (e) Not all gods are immortal.

Show solution

(a) ∀x(Gx → ¬Mx) or ¬∃x(Gx ∧ Mx). (b) ∀x(Mx → Hx). (c) ∃x(Hx ∧ ¬Mx). (d) Gz → ¬∀x(Gx → Mx). (e) ¬∀x(Gx → ¬Mx), equivalently ∃x(Gx ∧ Mx).

Exercise 6.2

Show solution

Exercise 6.5

Translate using identity (Px: x is a planet; Mxy: x is a moon of y; e: Earth): (a) Earth has exactly one moon. (b) There are at least two planets. (c) Every planet other than Earth is uninhabited (Ix: x is inhabited).

Show solution

(a) ∃x(Mxe ∧ ∀y(Mye → y = x)). (b) ∃x∃y(Px ∧ Py ∧ x ≠ y). (c) ∀x((Px ∧ x ≠ e) → ¬Ix).

Exercise 6.6

Using Russell's theory, give both readings of “The greatest prime number is not odd” and say which is true. (There is no greatest prime: Euclid proved there are infinitely many.)

Show solution

With Gx: x is a greatest prime, Ox: x is odd. Narrow-scope negation: ∃x(Gx ∧ ∀y(Gy → y = x) ∧ ¬Ox) — false, since nothing satisfies G. Wide-scope negation: ¬∃x(Gx ∧ ∀y(Gy → y = x) ∧ Ox) — true, for the same reason.

Exercise 6.7

Explain why ∃x(Px → Wx) is a bad translation of “Some philosophers are wise”. Describe an interpretation in which it is true but “Some philosophers are wise” is false.

Show solution

A conditional is true whenever its antecedent is false, so ∃x(Px → Wx) is true as soon as there is any non-philosopher, regardless of whether any philosopher is wise. Example:

Interpretation
  • Domain: {1, 2}
  • Extension of P: {1}
  • Extension of W: {}
In this interpretation
  • ∃x(Px → Wx) is true
  • ∃x(Px ∧ Wx) is false
