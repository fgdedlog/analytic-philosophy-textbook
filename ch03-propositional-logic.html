Propositional logic: language and translation

Learning objectives

  • explain why logicians use a formal language;
  • state the vocabulary and formation rules of propositional logic and decide whether a string is a well-formed formula;
  • identify the main connective and the scope of each connective in a formula;
  • translate English sentences into propositional logic, including the tricky cases: “only if”, “unless”, “neither … nor”, “not both”, necessary and sufficient conditions, and exclusive “or”;
  • recognise what propositional logic cannot capture.

Why a formal language?

Chapter 2 showed that validity depends on form. To study form precisely we need a way of displaying it that strips away irrelevant content and removes ambiguity. Ordinary English is wonderfully flexible but it is also ambiguous. “I saw the man with the telescope” has two readings; “Everyone didn't come” can mean that nobody came or that not everybody did. A formal language is an artificial language with a precisely specified vocabulary and grammar, designed so that every sentence has exactly one structure.

The first formal language we study is the language of propositional logic (also called sentential logic, or the propositional calculus). Its basic units are whole sentences, and it studies how sentences are combined using words like “not”, “and”, “or”, “if … then” and “if and only if”. Propositional logic cannot see inside simple sentences — it cannot represent the difference between “Socrates is wise” and “Someone is wise”. That is the job of predicate logic (Chapter 6).

The vocabulary

The language has three kinds of symbol.

  1. Sentence letters: p, q, r, s, … (and, if we need more, p₁, p₂, …). Each stands for a simple declarative sentence. Some books use capitals (P, Q, R); the interactive tools accept both.
  2. Connectives:
    SymbolNameTypical EnglishCompound is called
    ¬negationnot, it is not the case thata negation
    ∧conjunctionand, but, althougha conjunction (parts: conjuncts)
    ∨disjunctionor (inclusive)a disjunction (parts: disjuncts)
    →conditionalif … thena conditional (parts: antecedent and consequent)
    ↔biconditionalif and only ifa biconditional
    Other symbols you may meet in other books: ~ or − for ¬; & or · for ∧; ⊃ for →; ≡ for ↔.
  3. Brackets: ( and ).

We will also use the symbol ⊥ (“falsum”), a sentence that is always false; it is useful in proofs (Chapter 5).

Formation rules

The syntax of the language says which strings of symbols are well-formed formulas (wffs, or just formulas). We state the rules using capital letters A, B as metavariables: they are not part of the language but stand for any formula.

  1. Every sentence letter is a formula. So is ⊥.
  2. If A is a formula, so is ¬A.
  3. If A and B are formulas, so are (A ∧ B), (A ∨ B), (A → B) and (A ↔ B).
  4. Nothing else is a formula.

These rules are recursive: complex formulas are built from simpler ones, step by step. Any formula can be traced back to sentence letters by a construction tree. For example, ¬(p ∧ q) → r is built like this:

  • p, q, r are formulas (rule 1);
  • so (p ∧ q) is a formula (rule 3);
  • so ¬(p ∧ q) is a formula (rule 2);
  • so (¬(p ∧ q) → r) is a formula (rule 3).

Conventions. Strictly, the rules put brackets round every binary compound. To reduce clutter we adopt two conventions: (1) we may drop the outermost pair of brackets, writing p ∧ q for (p ∧ q); (2) ¬ applies to the smallest formula immediately after it, so ¬p ∧ q means (¬p ∧ q), not ¬(p ∧ q). Otherwise we always write brackets. (The interactive tools also understand a full precedence ordering — ¬, then ∧, ∨, →, ↔ — and read p → q → r as p → (q → r). But in your own work, use brackets.)

Which are well-formed?

  • ¬¬p — yes (rule 2 twice).
  • p¬q — no: ¬ is not a binary connective.
  • (p ∧ q ∨ r) — no, strictly: the rules never produce a bracket containing two binary connectives at the same level. It must be ((p ∧ q) ∨ r) or (p ∧ (q ∨ r)), which mean different things.
  • (p → (q ↔ ¬r)) — yes.
  • → p q — no (though this is well formed in “Polish notation”, a bracket-free notation that puts connectives first).

Main connective and scope

The main connective of a formula is the one added last in its construction. It determines what kind of formula it is: ¬(p ∧ q) → r is a conditional (main connective →), whose antecedent is the negation ¬(p ∧ q). The scope of a connective is the formula(s) it applies to: in ¬(p ∧ q) the negation has the conjunction p ∧ q in its scope; in ¬p ∧ q its scope is just p.

Finding the main connective is the first step in almost everything you will do: computing truth values, choosing proof rules, translating back into English. A reliable method: the main connective is the only binary connective not enclosed in any brackets (after restoring the outer brackets mentally), or, if there is none, the initial ¬.

Quick check What is the main connective of ¬(p ∨ q) ↔ (¬p ∧ ¬q)?

The ↔ is the only binary connective outside all brackets. The formula is a biconditional.

Quick check What is the main connective of ¬(p → q) ∨ r?

By convention ¬ takes the smallest formula after it, here (p → q). The disjunction joins ¬(p → q) and r.

Translating English: the basics

To translate, first give a key (or “dictionary”) assigning sentence letters to the simple sentences, then rebuild the English sentence with connectives. Choose letters for positive simple sentences and express negation with ¬.

Key

r: It is raining. w: The wind is blowing. c: The match is cancelled.

It is not raining.¬r
It is raining and the wind is blowing.r ∧ w
It is raining but the wind is not blowing.r ∧ ¬w
Either it is raining or the wind is blowing.r ∨ w
If it is raining, the match is cancelled.r → c
The match is cancelled if and only if it is raining.c ↔ r
If it is raining and windy, the match is cancelled.(r ∧ w) → c
It is raining, and if the wind is blowing the match is cancelled.r ∧ (w → c)

Conjunction. “But”, “although”, “however”, “yet”, “moreover”, “whereas” and “even though” all translate as ∧. They differ from “and” in suggesting contrast or surprise, but the contrast does not affect truth: “It is raining but I am happy” is true exactly when it is raining and I am happy. Propositional logic captures truth conditions, not every shade of meaning.

Not every “and” joins sentences: “Ann and Bob are married” may mean they are married to each other, which is not the conjunction “Ann is married and Bob is married”. And sometimes “and” carries temporal order: “She got married and got pregnant” suggests a different sequence from “She got pregnant and got married”. Logicians usually treat such order as an implicature rather than part of the truth conditions (Chapter 10).

Negation. Watch for negation hidden inside words: “The match is uncancelled”, “Nobody won”, “It is false that…”. Also watch its scope: “It is not the case that it is raining and windy” is ¬(r ∧ w), while “It is not raining and it is windy” is ¬r ∧ w.

Translate It is raining but the match is not cancelled.

Key: r: it is raining; c: the match is cancelled

Model answer: r ∧ ¬c. "But" is conjunction.

Translate It is not the case that both it is raining and the wind is blowing.

Key: r: it is raining; w: the wind is blowing

Model answer: ¬(r ∧ w). The negation has the whole conjunction in its scope. Equivalent (by De Morgan): ¬r ∨ ¬w.

Conditionals: “if”, “only if”, and conditions

The conditional is the hardest connective to translate. Its formal meaning is given in Chapter 4: A → B is false only when A is true and B false. For now, focus on getting antecedent and consequent the right way round.

A only if B.A → B
B provided that A. / B in case A. / Given A, B.A → B

“If” versus “only if”

This is the single most common translation error. Compare:

  • “You will pass if you score 40%.” — scoring 40% guarantees passing: s → p.
  • “You will pass only if you score 40%.” — scoring 40% is required for passing; you cannot pass without it: p → s.

The trick: “if” introduces the antecedent; “only if” introduces the consequent. “A only if B” says that A cannot be true without B, i.e. if A is true then B is true. A useful check: “A only if B” is equivalent to “if not B then not A” (¬B → ¬A), which is the contrapositive of A → B.

The position of the clause in the English sentence does not matter: “If you score 40%, you pass” and “You pass if you score 40%” both translate as s → p.

Necessary and sufficient conditions

A sufficient condition guarantees; a necessary condition is required. Being a square is sufficient for being a rectangle (square → rectangle); having four sides is necessary for being a square (square → four sides). Notice that in both cases the arrow points from the sufficient condition to the necessary one. “A is necessary for B” therefore becomes B → A.

Translate You will get the job only if you have a degree.

Key: j: you get the job; d: you have a degree

Model answer: j → d. "Only if" introduces the consequent. Having a degree is necessary for getting the job.

Translate You will get the job if you have a degree.

Key: j: you get the job; d: you have a degree

Model answer: d → j. "If" introduces the antecedent.

Translate Having a ticket is necessary for boarding the train.

Key: t: you have a ticket; b: you board the train

Model answer: b → t. A necessary condition is the consequent: if you board, you have a ticket.

Translate The alarm sounds if and only if there is smoke.

Key: a: the alarm sounds; s: there is smoke

Model answer: a ↔ s.

“Unless”

“A unless B” means: if not B, then A. “The match will go ahead unless it rains” = “If it does not rain, the match will go ahead”: ¬r → g. Now ¬r → g is equivalent to r ∨ g, so the standard rule is simple:

Translate “unless” as ∨. “A unless B” becomes A ∨ B (equivalently ¬B → A).

Does “The match will go ahead unless it rains” also say that if it rains, the match will not go ahead? Many speakers hear it that way, which would make it g ↔ ¬r (an exclusive reading). Logicians standardly take the weaker, inclusive reading as the literal content and treat the stronger reading as something often suggested by context. The weaker reading is safer: “I'll go to the party unless I'm ill” is not obviously falsified if I turn up ill. But if context makes the stronger meaning clear, translate it.

Translate The picnic will go ahead unless it rains.

Key: p: the picnic goes ahead; r: it rains

Model answer: p ∨ r. Standard inclusive reading: if it does not rain, the picnic goes ahead. Equivalent to ¬r → p.

Translate Unless you revise, you will not pass.

Key: r: you revise; p: you pass

Model answer: ¬p ∨ r. "Unless B, A" is "A unless B": ¬p ∨ r, equivalently ¬r → ¬p, equivalently p → r (passing requires revising).

“Or”: inclusive and exclusive

A ∨ B is inclusive: it is true when at least one disjunct is true, including when both are. Sometimes English “or” seems exclusive: “You may have soup or salad” (but not both). The exclusive reading — A or B but not both — can be expressed in several equivalent ways:

(A ∨ B) ∧ ¬(A ∧ B)   or   ¬(A ↔ B)   or   (A ∧ ¬B) ∨ (¬A ∧ B)

Translate as inclusive unless the exclusivity is clearly part of what is said (“either … or … but not both”). Often the “not both” is understood from background knowledge (you cannot be both in London and in Paris at noon) and need not be stated; including it does no harm, though.

Translate Either the butler or the gardener did it, but not both.

Key: b: the butler did it; g: the gardener did it

Model answer: (b ∨ g) ∧ ¬(b ∧ g). Exclusive "or". Any equivalent form, such as ¬(b ↔ g), is accepted.

“Neither … nor”, “not both”, “not either”

EnglishTranslationEquivalent
Neither A nor B.¬A ∧ ¬B¬(A ∨ B)
Not both A and B.¬(A ∧ B)¬A ∨ ¬B
Not either A or B.¬(A ∨ B)¬A ∧ ¬B

These equivalences are De Morgan's laws, which you will prove in Chapter 4. Notice that “not both” (¬(A ∧ B)) is much weaker than “neither” (¬A ∧ ¬B): “I didn't eat both the cake and the pie” is true if I ate just the cake.

Translate Neither Jo nor Sam came to the party.

Key: j: Jo came; s: Sam came

Model answer: ¬j ∧ ¬s. Equivalently ¬(j ∨ s).

Translate Jo and Sam didn't both come to the party.

Key: j: Jo came; s: Sam came

Model answer: ¬(j ∧ s). "Not both": at least one of them did not come.

Longer sentences: a method

For complex sentences, work from the outside in.

  1. Identify the simple sentences and give a key.
  2. Find the main connective of the English sentence — often signalled by a comma, “either”, “both”, or the position of “if”.
  3. Translate the main structure with placeholders, then fill in each part.
  4. Check by translating your formula back into English, and by asking whether the two agree in every situation.

Worked example

“If the government raises taxes and cuts spending, then unless the economy grows, unemployment will rise.”

Key: t: the government raises taxes; s: the government cuts spending; g: the economy grows; u: unemployment rises.

Main connective: the opening “If … then”. Antecedent: “the government raises taxes and cuts spending” = t ∧ s. Consequent: “unless the economy grows, unemployment will rise” = “unemployment will rise unless the economy grows” = u ∨ g.

Translation: (t ∧ s) → (u ∨ g).

Worked example

“The patient will recover only if she has the operation and does not catch an infection, but she will not have the operation unless the surgeon is available.”

Key: r: she recovers; o: she has the operation; i: she catches an infection; a: the surgeon is available.

Main connective: “but” (∧). Left: “r only if (o and not i)” = r → (o ∧ ¬i). Right: “not o unless a” = ¬o ∨ a (equivalently o → a).

Translation: (r → (o ∧ ¬i)) ∧ (¬o ∨ a).

Translate If the government raises taxes and cuts spending, then unless the economy grows, unemployment will rise.

Key: t: taxes are raised; s: spending is cut; g: the economy grows; u: unemployment rises

Model answer: (t ∧ s) → (u ∨ g).

Translate You can have dessert only if you eat your vegetables, and if you eat your vegetables you can watch television.

Key: d: you can have dessert; e: you eat your vegetables; t: you can watch television

Model answer: (d → e) ∧ (e → t).

Common pitfalls

  • Reversing “only if”. “A only if B” is A → B, not B → A.
  • Using a letter for a negative sentence. If p means “the shop is closed” and q “the shop is open”, the logic cannot see that they are related. Use p and ¬p.
  • Misplacing negation. “All that glitters is not gold” and “It is not the case that if you study you will pass” need care: the second is ¬(s → p), which (as Chapter 4 shows) says you study and do not pass — probably not what the speaker meant, who more likely meant “studying does not guarantee passing”, something propositional logic cannot express.
  • Treating “because” as a connective. “The match was cancelled because it rained” is not truth-functional: its truth depends on more than the truth values of its parts. The best propositional logic can do is the conjunction c ∧ r, which loses the causal claim.
  • Forgetting brackets. p ∧ q → r is ambiguous on the strict formation rules: write (p ∧ q) → r or p ∧ (q → r).

The limits of propositional logic

Propositional logic treats simple sentences as unanalysed blocks. That makes it blind to arguments whose validity depends on the internal structure of sentences:

  1. P1All philosophers are mortal.
  2. P2Hypatia is a philosopher.
  3. CHypatia is mortal.

In propositional logic this is p, q ∴ r — invalid. But the argument is plainly valid. Its validity depends on the words “all” and “is”, which only predicate logic can represent. Propositional logic also cannot represent non-truth-functional connectives such as “because”, “necessarily”, “believes that” or the counterfactual “if it had been…, it would have been…” (Chapter 9). Within these limits, however, it is a precise and powerful tool, and it is the foundation for everything that follows.

Summary

  • Propositional logic has sentence letters, five connectives (¬ ∧ ∨ → ↔) and brackets; formation rules define the well-formed formulas recursively.
  • Every formula has a unique main connective; the scope of a connective is what it applies to.
  • “If A, B” and “B if A” are both A → B; “A only if B” is also A → B. “If” introduces antecedents, “only if” introduces consequents.
  • Necessary conditions are consequents; sufficient conditions are antecedents.
  • “A unless B” is A ∨ B; “neither A nor B” is ¬A ∧ ¬B; “not both” is ¬(A ∧ B); exclusive “or” is (A ∨ B) ∧ ¬(A ∧ B).
  • Propositional logic captures truth conditions, not every nuance, and cannot represent internal sentence structure or non-truth-functional connectives.

Key terms

Formal language
An artificial language with precisely specified symbols and rules of formation.
Sentence letter
In propositional logic, a letter standing for a simple declarative sentence.
Connective
A symbol that builds sentences from sentences: ¬, ∧, ∨, →, ↔.
Well-formed formula
A string of symbols built up according to the formation rules of a formal language.
Syntax
The rules governing which strings of symbols are well-formed, independently of meaning.
Main connective
The connective with the widest scope in a formula; it determines the formula's type.
Scope
The part of a formula governed by a connective or quantifier.
Negation
A sentence of the form ¬A, "not A"; true just when A is false.
Conjunction
A sentence of the form A ∧ B, "A and B"; true just when both conjuncts are true.
Disjunction
A sentence of the form A ∨ B, "A or B" (inclusive); true when at least one disjunct is true.
Conditional
A sentence of the form A → B, "if A then B".
Antecedent
The "if" part of a conditional: in A → B, A.
Consequent
The "then" part of a conditional: in A → B, B.
Biconditional
A sentence of the form A ↔ B, "A if and only if B"; true when A and B have the same truth value.
Necessary condition
A is necessary for B when B cannot hold without A: "B only if A", B → A.
Sufficient condition
A is sufficient for B when A guarantees B: "if A then B", A → B.
Truth-functional
A connective is truth-functional when the truth value of the compound depends only on the truth values of its parts.

Exercises

Exercise 3.1

Which of the following are well-formed formulas (allowing the conventions about outer brackets and ¬)? (a) ¬(p ∨ q) (b) (p ∧) q (c) p → (q → (r → s)) (d) ¬¬¬p ∨ ¬q (e) (p ↔ q)) (f) p ∨ q ∨

Show solution

(a) yes; (b) no; (c) yes; (d) yes — main connective ∨; (e) no (unbalanced brackets); (f) no.

Exercise 3.2

Give the main connective of each formula: (a) ¬p ∧ q (b) ¬(p ∧ q) (c) (p → q) ↔ (¬q → ¬p) (d) p → (q ∨ r) (e) ¬(p → q) → ¬r

Show solution

(a) ∧; (b) ¬; (c) ↔; (d) →; (e) the second → (the one outside the brackets).

Exercise 3.3

Using the key s: Sam sings; d: Dee dances; m: the music plays, translate: (a) Sam sings only if the music plays. (b) Dee dances if the music plays. (c) Neither Sam sings nor Dee dances. (d) Sam sings unless Dee dances. (e) The music playing is necessary and sufficient for Dee dancing. (f) If the music plays, Sam sings or Dee dances, but not both.

Show solution

(a) s → m; (b) m → d; (c) ¬s ∧ ¬d; (d) s ∨ d; (e) m ↔ d; (f) m → ((s ∨ d) ∧ ¬(s ∧ d)).

Exercise 3.4

Translate into natural English, using the key of Exercise 3.3: (a) ¬(s ∧ d) (b) ¬m → (¬s ∧ ¬d) (c) d → (m ∧ s)

Show solution

(a) Sam doesn't sing and Dee dance together (they don't both perform). (b) If the music doesn't play, neither Sam sings nor Dee dances. (c) Dee dances only if the music plays and Sam sings.

Exercise 3.5

Explain why “You will pass only if you revise” does not mean the same as “If you revise, you will pass”. Give a situation in which one is true and the other false.

Show solution

With p: you pass and r: you revise, the first is p → r (revising is necessary for passing); the second is r → p (revising is sufficient). Situation: you revise but fail. Then “if you revise you will pass” is false, but “you will pass only if you revise” is true (you didn't pass without revising — indeed you didn't pass at all).

Exercise 3.6

Translate, giving your key: “If Parliament passes the bill, the law changes, unless the courts strike it down; and the courts will strike it down only if it is unconstitutional.”

Show solution

Key: b: Parliament passes the bill; l: the law changes; c: the courts strike it down; u: it is unconstitutional. Translation: (b → (l ∨ c)) ∧ (c → u). (The first conjunct could also be read as (b → l) ∨ c; the reading on which “unless” attaches to the consequent seems more natural, but the ambiguity is worth noting. In fact the two readings are logically equivalent here.)
