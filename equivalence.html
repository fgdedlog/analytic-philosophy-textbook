Equivalence and entailment checker

Enter two formulas of propositional logic, A and B. The checker tells you whether they are logically equivalent, whether one entails the other, or neither — and shows the rows of the truth table where they come apart.

What the verdicts mean

  • Equivalent: A and B are true in exactly the same rows. Each can replace the other anywhere without changing truth value.
  • A entails B (written A ⊨ B): there is no row in which A is true and B false. The argument “A, therefore B” is valid.
  • Neither: each can be true while the other is false.

The same syntax as the truth-table generator is accepted. For practice translating English into symbols, see the practice quizzes, which use this checker to accept any correct equivalent answer.
